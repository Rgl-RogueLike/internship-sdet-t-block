# Bug Report UI-003

## Некорректное текстовое сообщение при отсутствии результатов поиска

## Предусловия
1. Пользователь авторизован в Яндекс.Диске.
2. На диске загружены тестовые файлы.

## Шаги воспроизведения
1. Открыть Яндекс.Диск (`https://disk.yandex.ru/`).
2. Ввести в поле поиска строку, которая не совпадает с названиями существующих файлов (например, `nonexistent_file`).
3. Выполнить поиск.

## Фактический результат
Отображается сообщение "Ничего не нашлось" с предложением искать в корзине или истории.

## Ожидаемый результат
Отображается сообщение строго соответствующее требованиям: "В вашем Диске не найдено файлов или папок по запросу nonexistent_file".

## Окружение
- Браузер: Mozilla Firefox 152.0.5
- ОС: Windows 11
- Сервис: Яндекс.Диск Web
