# Bug Report UI-002

## Поиск не находит файлы, находящиеся в корзине, без дополнительного клика

## Предусловия
1. Пользователь авторизован в Яндекс.Диске.
2. На диске существует файл.
3. Файл перемещен в корзину.

Пример имени файла:
`deleted_file.txt`

## Шаги воспроизведения
1. Открыть Яндекс.Диск (`https://disk.yandex.ru/`).
2. Переместить файл `deleted_file.txt` в корзину.
3. Ввести название файла `deleted_file` в поле поиска.
4. Выполнить поиск.

## Фактический результат
Файл не отображается в результатах поиска. Для его обнаружения необходимо вручную нажимать на ссылку "Искать в корзине".

## Ожидаемый результат
Файл, находящийся в корзине, отображается в общих результатах поиска по введенному запросу.

## Окружение
- Браузер: Mozilla Firefox 152.0.5
- ОС: Windows 11
- Сервис: Яндекс.Диск Web
