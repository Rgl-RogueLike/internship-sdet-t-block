# Bug Report UI-001

## Поиск файлов по специальным символам не фильтрует результаты по запросу

## Предусловия
1. Пользователь авторизован в Яндекс.Диске.
2. На диске загружены тестовые файлы.
3. Среди файлов есть файл с именем, содержащим специальный символ.

Пример имени файла:
`test_file5%12;.txt`

## Шаги воспроизведения
1. Открыть Яндекс.Диск (`https://disk.yandex.ru/`).
2. Ввести в поле поиска специальный символ `%`.
3. Выполнить поиск.

## Фактический результат
В результате поиска отображаются все файлы с диска, независимо от введенного специального символа.

## Ожидаемый результат
В результатах поиска отображаются только файлы и папки, имена которых содержат введенный специальный символ %.

## Окружение
- Браузер: Mozilla Firefox 152.0.5
- ОС: Windows 11
- Сервис: Яндекс.Диск Web
