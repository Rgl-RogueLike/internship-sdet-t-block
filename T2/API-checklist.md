# API Check-list

## Предусловия

- Получен валидный OAuth-токен Яндекс.Диска.

## Результаты тестирования

| № | Проверка | Ожидаемый результат | Фактический результат | Статус |
|----|----------|---------------------|-----------------------|--------|
| 1 | Создание новой папки с корректными параметрами | Получен HTTP-код `200`. Папка создана по указанному пути | Получен HTTP-код `201`. Папка создана ([Bug API-001](API/API-001-create-folder-success-status-code.md)) | Fail |
| 2 | Создание папки по несуществующему пути | Получен HTTP-код `400`. Папка не создана | Получен HTTP-код `409`. Папка не создана. Ответ содержит ошибку `DiskPathDoesntExistsError` ([Bug API-002](API/API-002-create-folder-nonexistent-path-status-code.md)) | Fail |
| 3 | Создание папки по уже существующему пути | Получен HTTP-код `400`. Новая папка не создана | Получен HTTP-код `409`. Новая папка не создана. Ответ содержит ошибку `DiskPathPointsToExistentDirectoryError` ([Bug API-003](API/API-003-create-folder-existing-path-status-code.md))  | Fail |
| 4 | Запрос без Authorization token | Получен HTTP-код `401`. Папка не создана | Получен HTTP-код `401`. Папка не создана | Pass |
| 5 | Запрос с неверным Authorization token | Получен HTTP-код `401`. Папка не создана | Получен HTTP-код `401`. Папка не создана | Pass | 
| 6 | Проверка формата ответа при успешном создании | Ответ содержит поля `method`, `href`, `templated`. | Ответ содержит поля `method`, `href`, `templated` | Pass |
| 7 | Проверка тела ответа при ошибке | Ответ содержит поля `message`, `description`, `error` | Ответ содержит поля `message`, `description`, `error` | Pass |
| 8 | Запрос с пустым значением параметра `path` | Получен HTTP-код `400`. Папка не создана | Получен HTTP-код `400`. Папка не создана | Pass |
| 9 | Запрос без параметра `path` | Получен HTTP-код `400`. Папка не создана | Получен HTTP-код `400`. Папка не создана | Pass |
| 10 | Запрос без заголовка `Content-type` | Получен HTTP-код `400`. Папка не создана | Получен HTTP-код `201`. Папка создана ([Bug API-004](API/API-004-missing-content-type.md)) | Fail |
| 11 | Проверка работы параметра `fields` (например `fields=method`) | Ответ 200 содержит только запрошенные атрибуты | Ответ 200 содержит только запрошенные атрибуты | Pass |
