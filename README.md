# QA Internship

Репозиторий содержит выполненные задания по блоку **«Теория тестирования»**. В ходе выполнения заданий были продемонстрированы навыки работы с требованиями, составление тест-планов по стандарту IEEE 829, применения техник тест-дизайна и оформления баг-репортов.

## Используемые инструменты и технологии

- API-тестирование: Postman, Swagger UI (Yandex API).
- Документация: Markdown, Test-plan (IEEE 829), Bug Reports, Check-list.
- Техники тест-дизайна: Классы эквивалентности, Анализ граничных значений, Попарное тестирование, Тестирование состояний и переходов, Предугадывание ошибок.

## Структура проекта

- **[T1: Написание тест-кейсов](T1/)** — Разработка плана тестирования и тест-кейсов для REST API получения статуса продукта. Покрытие позитивных и негативных сценариев, валидация параметров и токенов авторизации.
- **[T2: Написание Bug Report](T2/)** — Тестирование требований и системы (UI и API Яндекс.Диска). Составление чек-листов, заведение инструментно-независимых баг-репортов (HTTP-коды, JSON-схемы, валидация заголовков).
- **[T3: Составление тест-плана](T3/)** — Разработка детального тест-плана для REST API расчета стоимости продукта. Покрытие бизнес-логики (нарастающий итог, партионность).
- **[T4: План тестирования микросервисов](T4/)** — Составление плана интеграционного тестирования асинхронного взаимодействия Сервиса А и Сервиса Б через брокер RabbitMQ (AMQP). Тестирование очередей (FIFO), таймаутов, изменения состояний и отказоустойчивости.
